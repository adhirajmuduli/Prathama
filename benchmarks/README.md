# Performance evidence

`latest.json` is generated by `python scripts/benchmark.py`. It records the
machine, Python version, repeat counts, input sizes, and wall-clock results.
Rerun it on the release commit and archive both the JSON and commit identifier.

The script measures validation, IDW and KDE surface generation at three input
sizes, and an approximately 10-second deterministic IDW MP4 export. These are
server CPU measurements; MapLibre display performance is outside the scientific
surface pipeline and is not used to claim estimator throughput.
